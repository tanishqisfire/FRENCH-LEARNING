Introduction
=
This is a website which uses flask to run python and javascript both, its main purpose is to teach you french's pronunciation.

Architecture
=
- app.py , has different routes which are called by different buttons

- index2.css, contains the css, its very simple themed.

- index.html, contains different buttons's ids , boxes and is the main page which is shown to the user.

- index1.js, contains the functions, the buttons will perform when pressed and the permissions required for the audio and fetching, and gives out the result by colouring the words red or green.

Now more deeply about the code itself,

- generator.py, generates a sentence, which the user and the system will read using api or ollama, the prompt and the model can be changed through config.py

- tts.py, uses special downloded french voice, to read out loud the french sentence generated by generator.py

- phonemes.py, takes in the same sentence and generates its phonemes, in a particular order.

- listen.py, takes in user's audio and generates the phonemes's in a particular order

- the outputs of listen.py and phonemes.py are then compared in compare.py which uses levenshtien method, to find out the exact number of phonemes needed to be replaced/deleted/added to form the correct sentence, then it traces which exact phoneme it was talking about and then it labels them as match, substitution, deletion,insertion and then it groups the word together so we know these phonemes are this single word it also includes to ignore the differences as correct on particular scenarios mentioned in improve.py.

- pipeline.py, groups everything together, so index1.js and app.py arent a mess, it calls the original sentence, the reference, the heard, the no of phonemes need to be edited minimal, the listing of them as insertion/de... ,  and it gives ok(true) value when no problem is in a word, which is used in index1.js to color the word as green or red.

- Docker file was added as i was recommended to host the site on hugging face but as of july of 2026 they have made that service paid and i decided not to remove the docker file as it dosent harm ig.

- frenchpronunciation.command, is the lanucher which is the main way to demo the project.

INCONSISTENCIES!
= 
- it a very real possibilty for this code to flag different accents which are considered to be right pronunciation as wrong pronunciation so beaware it is a fairly inconsistent code which needs more improvement to be helpfull for real students as for the same word many phonemes could be considered as correct in different accent and it only ignores  common incosistencies rather than most of them.(if the word spoken is correct it will usually show it as correct unless audio is intreurpted by external sounds)

- tho if the entire sentence is shown as wrong even if spoken correctly is a very rare case which shouldnt happen as multiple accents were tested and it only caused trouble on specific words and most of the sentences were flagged correct and if it does happen then that may indicate a audio input problem.
